📅 Latest News & Updates



#### 1. Playwright v1.57 Release Date: Late November 2025 (Current Stable Version) Source: [GitHub Release Notes](https://github.com/microsoft/playwright/releases) & Official Blog Impact: Major

  • Chrome for Testing Switch: Playwright has switched its default browser binary from standard "Chromium" to "Chrome for Testing". This Google-supported flavor of Chrome is designed specifically for automation, offering higher fidelity to the real Google Chrome browser while maintaining a consistent versioned environment.
  • "Speedboard" Reporter Tab: The HTML reporter now includes a "Speedboard" tab that visualizes test execution times. It sorts tests by duration, making it easier to spot bottlenecks and "slowest tests" in your suite.
  • Smart WebServer Waiting: The webServer config now supports a wait property that accepts a Regular Expression (e.g., /Listening on port \d+/). This allows Playwright to wait for a specific console log message before starting tests, which is ideal for servers that don't expose a simple HTTP health check endpoint.
  • Locator Descriptions: You can now use locator.describe("Submit Button") to add custom labels to your locators. These labels appear in the Trace Viewer and error logs, making debugging significantly more readable than raw CSS/XPath selectors.


Action Items:
  • Upgrade: Run npm install -D @playwright/test@latest and npx playwright install to get the new binaries.
  • Verify: Ensure your CI pipelines accept the new "Chrome for Testing" binary paths (usually handled automatically by the Playwright install command).
  • Refactor: Replace complex webServer timeouts with the new regex-based wait property for faster and more reliable CI starts.


#### 2. Playwright MCP Server (AI Integration) Date: December 2025 (Versions 1.0.8 - 1.0.12) Source: [Playwright MCP GitHub](https://github.com/microsoft/playwright-mcp-server) Impact: Major (for AI workflows)

  • Summary: Microsoft released the Playwright Model Context Protocol (MCP) Server, a tool that allows AI assistants (like Claude Desktop or GitHub Copilot) to connect to and control a Playwright browser session.
  • Recent Updates:
* Auto-Install: The server now automatically detects and installs missing browsers (Chromium, Firefox, WebKit) without manual user intervention. * Enhanced Auth: Added support for Bearer tokens and custom headers, allowing AI agents to test authenticated routes more easily. * Security: Removed shell execution capabilities to make the browser-driving process safer when triggered by AI.

Action Items:
  • Experiment: If you use AI coding assistants, install the Playwright MCP server to let your AI agent "see" and "click" through your app to generate tests or debug issues.


#### 3. Breaking Changes & Deprecations Date: v1.57 Release Source: Official Changelog Impact: Critical

  • page.accessibility Removed: The page.accessibility API, which had been deprecated for 3 years, has been officially removed.
  • Action Item: If you still have legacy tests using page.accessibility.snapshot(), migrate them immediately to the @axe-core/playwright community package for accessibility testing.

  • Trace Viewer Upgrade: With v1.57, use the new locator.describe() feature to annotate your most critical buttons and inputs. When a test fails, the Trace Viewer will show "Clicked 'Submit Button'" instead of "Clicked locator('button[type="submit"]')", making it easier for non-devs to understand reports.
